# Yamanoha — The Mountain Silhouette Viewer

山の端 (Yamanoha) is a Japanese word for the faint line where mountain ridges meet the sky — a sight that has moved poets and wanderers for centuries.

This project reconstructs that silhouette computationally. Standing in a town in northern Tokyo and looking westward, one can see the layered ridgelines of the Tanzawa, Okumusashi, Okutama, and Chichibu ranges, with Mount Fuji appearing on clear days — yet few can name which peak is which.

So I built a program that computes the ridgelines of the mountain ranges from terrain data and identifies the peaks that form them.
